# Expanded Database Table Marts & Column Dictionary

This document provides an expanded, detailed dictionary of the database tables and columns used in the Collection AI system under the `BI_DWH` schema. It maps each field to its fully qualified table-column path, English object name expansion, Arabic translation, data types, nullability, and database comments to assist in manually filling out mapping checklists.

## 4. Output & Decision Tables (Reference)

These tables store the output from the scoring and decision engine.

### PIO_COLL_AI_MATRIX_RESULTS

Saves the integrated willingness and ability scores, composite priority, quadrant, SHAP risk drivers, and model tracking metadata.

* **`PIO_COLL_AI_MATRIX_RESULTS.CUST_INFO_ID`** (Customer Information ID / رقم تعريف العميل)
* **`PIO_COLL_AI_MATRIX_RESULTS.WILLINGNESS_SCORE`** (Willingness Score / درجة الرغبة في السداد)
* **`PIO_COLL_AI_MATRIX_RESULTS.ABILITY_SCORE`** (Ability Score / درجة القدرة على السداد)
* **`PIO_COLL_AI_MATRIX_RESULTS.PRIORITY_SCORE`** (Priority Score / درجة الأولوية)
* **`PIO_COLL_AI_MATRIX_RESULTS.CURRENT_QUADRANT`** (Current Quadrant / ربع التصنيف الحالي)
* **`PIO_COLL_AI_MATRIX_RESULTS.DAY_DATE`** (Processing Date / تاريخ المعالجة)
* **`PIO_COLL_AI_MATRIX_RESULTS.INST_CODE`** (Institution Code / رمز المؤسسة)
* **`PIO_COLL_AI_MATRIX_RESULTS.COUNTRY_CODE`** (Country Code / رمز الدولة)
* **`PIO_COLL_AI_MATRIX_RESULTS.MODEL_VERSION`** (Model Version / إصدار النموذج)
* **`PIO_COLL_AI_MATRIX_RESULTS.WILL_RISK_DRIVERS`** / **`WILL_POSITIVE_DRIVERS`** (Willingness SHAP Drivers / محركات فحص الرغبة)
* **`PIO_COLL_AI_MATRIX_RESULTS.ABIL_RISK_DRIVERS`** / **`ABIL_POSITIVE_DRIVERS`** (Ability SHAP Drivers / محركات فحص القدرة)
* **`PIO_COLL_AI_MATRIX_RESULTS.LAST_SCORED_AT`** (Last Scored At Timestamp / وقت آخر عملية احتساب)

### PIO_COLL_AI_NBA_ACTIONS

Saves compliance guardrail-filtered recommendations, reason codes, alternative rankings, and cached narratives.

* **`PIO_COLL_AI_NBA_ACTIONS.DAY_DATE`** (Business Date / تاريخ يوم العمليات)
* **`PIO_COLL_AI_NBA_ACTIONS.INST_CODE`** (Institution Code / رمز المؤسسة)
* **`PIO_COLL_AI_NBA_ACTIONS.COUNTRY_CODE`** (Country Code / رمز الدولة)
* **`PIO_COLL_AI_NBA_ACTIONS.CUST_INFO_ID`** (Customer Information ID / رقم تعريف العميل)
* **`PIO_COLL_AI_NBA_ACTIONS.RECOMMENDED_CHANNEL`** (Recommended Outreach Channel / قناة التواصل الموصى بها)
* **`PIO_COLL_AI_NBA_ACTIONS.RECOMMENDED_OFFER`** (Recommended Treatment / الإجراء أو العرض الموصى به)
* **`PIO_COLL_AI_NBA_ACTIONS.DECISION_REASON`** (Decision Audit Reason / سبب القرار للتتبع)
* **`PIO_COLL_AI_NBA_ACTIONS.AI_PAYLOAD`** (Narrative Context JSON Payload / تفاصيل سياق العميل للذكاء الاصطناعي)
* **`PIO_COLL_AI_NBA_ACTIONS.AI_NARRATIVE`** (Executive Narrative Summary / الملخص التنفيذي الذكي للمحصل)
* **`PIO_COLL_AI_NBA_ACTIONS.SCORED_ALTERNATIVES`** (Alternative Scored Decisions / القرارات البديلة المحتسبة)
* **`PIO_COLL_AI_NBA_ACTIONS.CREATED_AT`** / **`UPDATED_AT`** (Auditing Timestamps / طوابع التدقيق الزمني)
